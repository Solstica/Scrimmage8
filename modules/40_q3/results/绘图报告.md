## 3. 图3：双阈值最优层数状态带状图（推荐替代）

### 图的含义与读法

这是一张“扫描速率—最优新增层数”的状态图。横轴是扫描速率 `K/min`，纵轴两行分别对应 15℃ 和 10℃ 的截止阈值；每个色块表示在该扫描速率范围内，模型选出的最优新增层数 `n`。因此，读者沿某一温度行从左向右查看，就能直接得到“扫描速率提高时，需要增加几层”的分段结论。顶部图例给出四种蓝色色阶与 `n=0、1、2、3` 的对应关系，色块面积不代表时间、温度或样本量。

橙色窄带和两条橙色边界线表示模型定位出的层数切换区间：例如 15℃ 行在约 `1.21875—1.2265625 K/min` 从 `n=0` 切换到 `n=1`，在约 `1.359375—1.3671875 K/min` 从 `n=1` 切换到 `n=2`；10℃ 行的对应切换约为 `1.2890625—1.296875`、`1.4765625—1.484375` 和 `1.7109375—1.71875 K/min`。色块内部按区间中心排布只是为了让状态条连续可读，不能把中心值误当成精确临界速率。

图中可直接读出的结论是：在相同扫描速率下，10℃截止通常需要不低于 15℃截止的新增层数；随着扫描速率增大，两种阈值口径的最优层数均按 `0→1→2→3` 依次增加。该图表达的是离散方案选择和切换范围，不表达连续响应曲线，也不表达统计误差。

### 为什么改用这张图

原水平误差线图的切换区间只有 `0.0078125 K/min`，在论文尺寸下容易被符号遮住；阶梯图虽然能表达跳变，但读者仍需要从纵坐标读取层数。状态带状图把四种离散层数直接写在大色块内，两个温度各占一行，阅读路径更短，也不依赖小点。

### 画什么

横轴为扫描速率，纵轴为温度口径（15℃、10℃）。每行用四段连续色块表示 `n=0、1、2、3`；橙色窄带为真实切换区间的下界—上界。色块内部边界采用切换区间中心，仅用于连续排版，不能当作精确临界值。

### 数据表

`modules/40_q3/figures/editable/双阈值最优层数状态带状图.xlsx`  
工作表：`状态带`（四个层数状态段）和 `切换区间`（六个真实边界区间）。

绘图工具：Python 用于生成正式 PNG；因为两行区间条与温度行内窄切换带的组合在 Origin 中需要手工逐段布置，Python 更适合先验收最终刊载尺寸。正式数据仍以可编辑的 Origin 工作表为准，未将位图嵌入 Origin。

### Origin 选列

| 工作表 | 列 | 中文列名 | 角色 |
|---|---|---|---|
| 状态带 | A | 阈值口径 | 行分组：15℃、10℃ |
| 状态带 | B | 层数 n | 色块标签/类别 |
| 状态带 | C/D | 状态段下界/上界（K/min） | 矩形或区间条左右端点 |
| 切换区间 | A/B | 阈值口径/层数切换 | 区间说明 |
| 切换区间 | C/D | 区间下界/上界（K/min） | 橙色切换带左右端点 |

### Origin 操作

1. 导入 `双阈值最优层数状态带状图.xlsx`，以 `状态带` 工作表的 C、D、A、B 创建两行水平区间条；每一行按 `n` 分成四段。
2. 设置 X 轴范围 `1.18—1.80 K/min`，刻度 `1.2、1.3、…、1.8`；Y 轴只保留 `15℃、10℃` 两个类别标签。
3. `n=0、1、2、3` 使用由浅到深的蓝色，条带内部直接标注 `n=0` 等层数；不添加散点符号。
4. 根据 `切换区间` 工作表 C、D，在相应温度行叠加六个窄的橙色半透明矩形，并用两条橙色边界线标出下界和上界。
5. 图例只解释四种层数颜色；切换区间含义放在图注中，不再增加大段文字。

### 图上必须写的限制

色块表示模型选出的离散最优层数，不表示连续层数。橙色带是二分定位得到的切换区间，不是标准差、标准误或置信区间；色块的中心边界仅作显示定位。

## 4. 图4：边际有效时间变化（新增补充图）

### 画什么

比较相邻整数层数的有效时间变化：`Δt_eff(n)=t_eff(n)-t_eff(n-1)`。它不重复图1的绝对时间曲线，直接回答“增加一层是收益还是损失”。

### 数据表

`modules/40_q3/figures/editable/边际有效时间变化.csv`，48行×8列。

### Origin 选列

| 列 | 中文列名 | 角色 |
|---|---|---|
| A | 扫描速率（K/min） | Y轴速率类别 |
| B | 阈值口径 | 左/右面板分组 |
| C | 层数变化 | X轴分类：0→1、1→2、2→3 |
| D/E | 原有效时间/新增后有效时间（s） | 数值核对 |
| F | 边际有效时间 Δt_eff（s） | Z或格内数值 |
| G/H | 原新增层数/新增后层数 | 分组辅助列 |

### 坐标和色标

- 左面板标题：`15℃截止`；右面板标题：`10℃截止`。
- X轴：`层数变化`，顺序 `0→1、1→2、2→3`。
- Y轴：`扫描速率（K/min）`，显示实际八个速率。
- 色标：`边际有效时间 Δt_eff（s）`，0为收益/损失分界。
- 格内显示带符号的一位小数，如 `+14.0`、`−3.0`。

### Origin 操作

1. 导入 CSV，按 B列分别筛选15℃和10℃。
2. 选择 C、A、F，绘制离散热图或矩阵图；C为X分类，A为Y分类，F为Z。
3. 色标中心固定为0；正值用暖色，负值用冷色。
4. 格内保留带正负号数值，不连接不同速率。

### 图上必须写的限制

正值表示增加一层后有效时间增加，负值表示下降。热图只排列已计算的离散速率，不表示连续响应面。
