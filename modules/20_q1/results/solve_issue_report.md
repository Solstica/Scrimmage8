# Q1 求解阻塞报告

- 问题：第 13 题问题 1
- 模型 ID：`WHUT13-Q1-THERMAL`
- 当前状态：**模型级阻塞已解除，允许继续正式计算；DSC 扫描速率作为显式不确定参数处理**

## 1. 已确认的旧版模型问题

旧版模型把附件 DSC 曲线直接写成 `Q_2(T)=rho_2*q_pcm(T)`，即只依赖当前温度的持续功率源。隐式有限体积解运行至 500 h 后出现稳定放热：PCM 仍停留在实测放热区间，并以与环境散热相同的功率持续输出热量。500 h 内累计放热达到 `1.1885068337e9 J`，折合约 `3.256344300e9 J/kg`，且继续延长时间仍会增长。

该诊断证明：持续温度功率源没有相变进度或累计能量上限，会形成非物理的无限放热稳态。减小时间步、增加模态数或延长计算时间只能提高该错误稳态的数值精度，不能修复模型语义。

## 2. 人体边界语义已修正

附件 2 明确规定“测试时，假设人体的温度为 37℃”。因此旧版动态人体热容节点 `T_h(t)` 已撤销：

- 人体作为恒温热源 `T_b=37 ℃`；
- 人体--织物之间采用附件给出的静止站立对流系数 `h_b=3.0 W/(m²·K)`；
- 内侧边界为 `-k_1 T_x(0,t)=h_b[T_b-T_1(0,t)]`；
- 不再使用 `C_h dT_h/dt`、`beta_h` 或人体积分能量平衡闭合式；
- 两个材料界面的斜率 `beta_12,beta_23` 由两处热流连续条件直接闭合。

题面规定人体表面温度低于 15℃工作困难、低于 10℃有生命危险，而附件又固定测试人体温度为 37℃。本模型不显式建立皮肤层，因此将内层织物贴近人体一侧 `T_in(t)=T_1(0,t)` 作为人体表面附近接触界面的等效评价温度，阈值时间定义为 `T_in` 首次降至 15℃、10℃ 的时刻。

因此旧版报告中动态人体 `T_h(500 h)=23.992698 ℃`、`t15=null`、`t10=null` 等结果均为 **STALE**；其对“持续功率源会无限放热”的诊断仍有效。

## 3. DSC 有限相变修正

对基线校正后的 DSC 放热峰定义 `p(T)>=0`，由归一化累计峰面积构造相对固化进度

`xi_DSC(T)=∫_T^Ts p(theta)dtheta / ∫_Tf^Ts p(theta)dtheta`，

并在固化温区外分别取 0 和 1。该比例只决定固化过程随温度的分配形状，恒定扫描速率在分子、分母中相消，因此附件温度--DSC 两列数据足以确定 `xi_DSC(T)` 的相对形状。

有限相变热写为

`Q_lat=rho_2*L_pcm*d(xi)/dt`，

单调降温主阶段可写为有效比热

`c_eff(T)=c_2-L_pcm*d(xi_DSC)/dT = c_2+L_pcm*p(T)/∫p(T)dT`。

数值实现必须保持相变不可逆：有限体积基线每个功能层单元独立保存 `xi_j`，采用 `xi_j^{n+1}=max(xi_j^n,xi_DSC(T_j^{n+1}))`；模态主算法可采用功能层平均温度的标量历史 `xi_bar`，并由有限体积结果检验该近似。

## 4. DSC 数据诊断

附件 1 共 357 个有效点，温度范围 `14.050--26.018 ℃`，平均相邻温差约 `0.03362 K/point`。两端原始放热值仍约为 `404 W/kg` 与 `400 W/kg`，说明不能把零线直接视为已完成基线校正。

当前操作性基线采用温区两端点之间的直线：

- 校正后曲线全部非负；
- 主峰温度 `20.622 ℃`；
- 校正峰值约 `3380.599 W/kg`；
- 未校正积分面积 `25198.270 W·K/kg`；
- 端点线性基线校正面积 `A_DSC=20385.458 W·K/kg`；
- 基线部分约占原始面积 `19.10%`；
- 端点线性校正后累计固化进度约为：`xi=0.10 -> 23.082 ℃`，`xi=0.50 -> 20.287 ℃`，`xi=0.90 -> 16.979 ℃`。

端点线性基线只作为本轮计算的操作基线，并非宣称其为唯一实验基线；后续若可可靠确定峰 onset/endset，应做替代基线比较。

## 5. 扫描速率反推与数量级判断

若 DSC 冷却扫描速率为 `v [K/min]`，则

`L_pcm = A_DSC*60/v = 1223127.48/v J/kg`。

附件温度点近似等间距，但 `0.03362 K/point` 只等于 `扫描速率 × 采样周期`，不能唯一恢复扫描速率。

数量级检查：

- 若假设 `1 s/point`，则 `v≈2.017 K/min`，对应 `L_pcm≈606 kJ/kg`；
- 若把 `0.03362 K/point` 错当成 `0.03362 K/min`，则 `L_pcm≈36.4 MJ/kg`，且整个约 12 K 温区扫描约 5.9 h，该数量级明显不适合作为本题基准；
- 因而点间距能证明数据来自近似匀速扫描，但不能证明扫描速率就是 `0.03362 K/s` 或 `0.03362 K/min`。

## 6. 建模师解除阻塞决定

原题缺失扫描速率，继续等待外部实验条件会阻塞后续 Q1--Q4。为完成训练赛计算，现将扫描速率作为显式建模不确定参数，而不再把它当待补“事实”。

正式计算采用：

- **基准工况**：`v0=5 K/min`，对应 `L_pcm0=244625.50 J/kg = 244.63 kJ/kg`；
- **敏感性工况 A**：`v=2 K/min`，对应 `L_pcm=611563.74 J/kg = 611.56 kJ/kg`；
- **敏感性工况 B**：`v=10 K/min`，对应 `L_pcm=122312.75 J/kg = 122.31 kJ/kg`。

上述 `v0=5 K/min` 是**题目缺失实验条件下的建模假设**，不是附件事实。其作用是给出主结果所需的能量尺度；`2--10 K/min` 的两端计算用于量化这一假设对 `t15/t10` 的影响。如果阈值时间在该范围内稳定，则主结论可视为对扫描速率假设稳健；若差异明显，正式结果中必须把扫描速率列为主要不确定来源并同时报告区间结果。
