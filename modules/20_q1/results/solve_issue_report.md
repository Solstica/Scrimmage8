# Q1 求解阻塞报告

- 问题：第 13 题问题 1
- 当前模型：人体单节点热容 + 三层瞬态导热 + 两侧对流 + PCM 温度相关放热
- 当前状态：**原模型闭合阻塞已解除，可进入正式数值实现**

## 已解除的阻塞

1. **人体侧边界**：附件给出人体状态对应的对流换热系数。Q1 静止站立取 `h_b=3.0 W/(m²·K)`，人体与内层织物之间采用 Robin 边界
   `-k_1 T_x(0,t)=h_b[T_h-T_1(0,t)]`。
2. **人体热容量**：人体热储存按 GB/T 42841-2023 所覆盖的人体冷热应激热平衡框架处理。该标准非等效采用 ISO 7933:2004 等国际标准；对应 PHS 热平衡体系采用人体比热 `c_h=3470 J/(kg·K)`。题目给 `m_h=60 kg`，故 `C_h=2.082e5 J/K`。
3. **人体面积**：附件 Stevenson 公式给出 `A_b=1.6521 m²`。人体能量平衡为
   `C_h dT_h/dt=-A_b h_b[T_h-T_1(0,t)]`。
4. **外侧边界**：不再采用 `T_3(L,t)=-40 ℃`。附件给出服装表面--外界自然对流公式
   `h_e=2.38[T_3(L,t)-T_inf]^0.25`，`T_inf=-40 ℃`，故
   `-k_3 T_x(L,t)=h_e[T_3(L,t)-T_inf]`。
5. **DSC 区间外处理**：根据题目“固化完成后不再放热”及附件实测温区，当前实现规定实测温区外 `q_pcm(T)=0`，不进行曲线外推。

## 求解结构变化

旧版推导中第一层和第三层误按 Dirichlet 边界处理。更新后：

- 第一层：Robin--Dirichlet，本征值满足 `tan(lambda*d1)=-k1*lambda/h_b`；
- 第二层：Dirichlet--Dirichlet，保留正弦本征展开，并在单个微小时间段内冻结 `q_pcm(T)`；
- 第三层：Dirichlet--Robin，在单个时间段内冻结 `h_e`，本征值满足 `tan(lambda*d3)=-k3*lambda/h_e`。

每个时间段将 `T_h,T_12,T_23` 作局部线性近似，未知斜率为 `beta_h,beta_12,beta_23`。两个材料界面的热流连续提供两个方程，人体时间段积分能量平衡提供第三个方程，因此当前时间段求解闭合。

## 仍需数值检查的事项

- DSC 原始数据的符号与 `mW/mg -> W/kg` 单位换算需在代码导入时核验。
- 功能层热源冻结和外侧 `h_e` 冻结属于时间步近似，必须比较 `Delta t` 与 `Delta t/2`。
- Robin 本征展开需要增加模态截断数 `M` 做收敛检查。
- 正式结果应再用隐式有限体积/有限差分作独立基准，比较 `T_h(t)`、关键界面温度和 `t15`。
- GB/T 42841-2023 的官方公开页面可核验标准状态、范围和采标关系，但不公开全文；`c_h=3470 J/(kg·K)` 的数值同时由 ISO 7933/PHS 公开文献支持，正文需保持这一来源边界。
