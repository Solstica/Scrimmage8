- **阈值修正**：题面给出“人体表面温度低于 15℃工作困难、低于 10℃有生命危险”，但附件同时固定人体测试温度为 37℃。本模型不另建皮肤层，因此将内层织物贴近人体一侧 `T_in(t)=T_1(0,t)` 作为人体表面附近接触界面的等效评价温度；`t15`、`t10` 分别取 `T_in` 首次降至 15℃、10℃ 的时刻。

- 服装外表面--环境自然对流使用附件公式：`h_e=2.38[T_3(L,t)-T_inf]^0.25`，`T_inf=-40 ℃`；`2.38` 只是无风自然对流经验关系中的系数，完整 `h_e` 才是表面对流换热系数。
- 初始条件统一取 `T_i(x,0)=37 ℃`。
- 第一层为 Robin--Dirichlet 本征展开；第二层为 Dirichlet--Dirichlet；第三层为 Dirichlet--Robin。
- 人体恒温后，每个微小时间段只有两个未知界面斜率 `beta_12,beta_23`，由两处材料界面的热流连续条件闭合；旧版 `beta_h` 和人体时间段积分能量平衡式全部删除。

## PCM / DSC 修正任务
- 旧版 `Q_2(T)=rho_2*q_pcm(T)` 被判定为模型语义错误：只要温度停留在实测放热区间，PCM 就会持续无限放热，与题目“固化完成后不再放热”冲突。
- 对基线校正后的 DSC 放热峰定义 `p(T)>=0`，由归一化累计峰面积直接反推出相对固化进度：
  `xi_DSC(T)=∫_T^Ts p(theta)dtheta / ∫_Tf^Ts p(theta)dtheta`，区间外分别取 0 和 1。
- 上述 `xi_DSC(T)` 的**形状不需要 DSC 扫描速率**：恒定扫描速率在累计焓占比的分子、分母中相消。
- 数值实现需加入历史约束 `xi^{n+1}=max(xi^n,xi_DSC(T^{n+1}))`，避免局部回温使已固化部分反向减少。
- 有限相变放热写成 `Q_lat=rho_2*L_pcm*d(xi)/dt`；单调冷却主阶段等价为有效比热
  `c_eff(T)=c_2-L_pcm*d(xi_DSC)/dT = c_2 + L_pcm*p(T)/∫p(T)dT`。
- 微小时间段内冻结 `c_eff(barT_2^n)`，第二层仍保持无源线性热方程结构，只更新 `alpha_2^n=k_2/(rho_2*c_eff^n)`；这与现有分离变量框架兼容。
- **当前唯一能量尺度缺口**：附件现有两列温度--DSC 数据只能确定相对固化进度，不能唯一确定绝对总潜热 `L_pcm`。需要继续查 DSC 扫描速率、原材料相变焓或等价的绝对焓数据；编程手不得自行补数值。
